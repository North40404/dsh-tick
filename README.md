# dsh-tick

为 DSH 会话安排定时任务：到点后唤醒模型执行。

## 它做什么

给会话排一条"到点叫我"的任务，三种节奏：

| 类型 | 参数 |
|---|---|
| 一次性 | 相对分钟数，或绝对时刻（必须带时区偏移） |
| 固定间隔 | `everyMinutes` |
| 随机间隔 | 每次从 `[minMinutes, maxMinutes]` 里重抽 |

到点后向该会话注入一段 **scratch**（写给未来自己的提示），模型据此决定这轮做什么。

## 关键约束

- **一个 job = 一次机会 + 一个意图**。不要把一个 job 塞进多种目的，否则频率、预算、补偿策略都无法分别设定
- **静默合法**：任务触发后模型可以什么都不说，但不能"宣布沉默"
- **没有通知通道**：tick 只往会话里追加消息，不响铃/弹窗（装了桥接类插件时消息可能被推到手机，那是对方的行为）
- 周期任务错过不会补发提醒，直接顺延；只有重要的一次性任务超容忍才留"错过的提醒"

## 注意

**这个包与插件市场里一个同名插件无关。** 发布前建议改名（例如 `pod-tick`），
否则插件市场会按名字把本地安装匹配到那一条目上。
