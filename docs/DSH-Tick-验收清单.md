## 二、扫描循环（**本轮重点**）

### 2.1 结构

```
apply()
 └─ ctx.effect(): setInterval(tick, scanIntervalMin×60s) + 启动后 3 秒先拍一次
      tick(): 防重入 → scan()
        scan():
          1. ensure() 懒初始化 store/jobs
          2. rollDay()      跨自然日清零
          3. classifyScan() 自检环（挂起/时钟倒退只告警）
          4. 心跳 lastScanAt（5 秒节流写盘）
          5. 总开关关闭 → 直接返回
          6. TTL 清理不可达任务
          7. 认领到期任务（inFlight 互斥）
          8. 并发评估（每任务独立等空闲）→ 串行落地（写盘/唤醒不并发）
```

### 2.2 用例

| # | 验收点 | 判定 | 状态 |
|---|---|---|---|
| L1 | **只有一处定时器** | 全插件仅 `setInterval(tick)` 一个周期定时器，无 per-job timer | ✅ 静态核对 |
| L2 | **防重入** | 上一轮未结束时跳过这一拍（`scanning` 标志） | ✅ 静态核对（间隔可低到 6 秒） |
| L3 | **心跳节流** | `lastScanAt` 最多每 5 秒写一次，短间隔不刷盘 | ✅ 静态核对 |
| L4 | **间隔热生效** | 保存新间隔 → 重建定时器（不是等重载） | ✅ 实测日志 `扫描间隔已调整为 0.5 分钟` |
| L5 | 到期判定 | 用当前 `clock.now()` 与 `job.nextDueAt` 比较 | ✅ 静态核对 |
| L6 | 并发评估 / 串行落地 | 等空闲互不阻塞；写盘与唤醒串行（store 是整文件写） | ✅ 实测两会话同时评估 |
| L7 | 认领互斥 | `inFlight` 覆盖「评估 + 落地」全生命周期 | ✅ 实测（等空闲期间下一拍不重复认领） |
| L8 | 失败退避 | 唤醒失败后 5 分钟内不重试（`lastErrorAt`） | ✅ 实测（busy-timeout 后不再刷） |
| L9 | 挂起分类只告警 | `suspended` 只记日志，补偿交给任务层 | ✅ 实测 `检测到长时间挂起：距上次扫描约 866 分钟` |
| L10 | 检测窗口下限 | factor 有 60 秒下限，短间隔不误判 | ✅ 静态核对 |
| L11 | 时钟倒退 | 只告警并按新日期重算计数 | 🧪 |
| L12 | 冷启动静默期 | 90 秒内不翻会话日志 | ✅ 实测 `冷启动 3 秒内跳过 token 统计` |
| L13 | 僵尸清理 | 不可达超 24h → 移除 + 留档 | ✅ 实测（临时把 TTL 缩到 20 秒验证） |
| L14 | **删除竞态** | 等空闲期间被删 → 不唤醒、不复活 | ✅ 实测 `等待期间已被删除，跳过本次唤醒` |
| L14b | **世代守卫** | 插件重载后，旧实例的残留异步放弃落地写入（防止用它自己的内存快照复活已删除任务） | ⬜ 已实现，待一次重载×删除的复现确认 |
| L15 | 总开关关闭 | 仍写心跳（防误判挂起），但不认领 | ✅ 实测 |
| L16 | 空转零 token | 无到期任务时不调用任何模型 | ✅ 日志无 wake 记录 |

### 2.3 循环相关的历史 bug（全部已修，留作回归点）

| bug | 现象 | 回归点 |
|---|---|---|
| 串行扫描 | 一个任务等空闲会挡住后面所有任务 | L6 |
| 重复触发 | 保存配置时重建 store，两实例导致任务被"复活" | 配置保存路径（P17） |
| 删除后复活 | 落地阶段用 `putJob`（不存在则新增） | L14 |
| 挂起后连发 | 周期任务过期时漏掉 `reschedule` 分支 → 醒来连发 | L9 + F10 |
| 定时器不重建 | 改间隔要重载才生效 | L4 |
| 重载后残留写入 | 重载时正在等空闲的旧 landing 用旧快照把已删任务写回（实测删后 6 秒复活） | L14b |
