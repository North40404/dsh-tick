# DSH-Tick

给 DSH 会话安排定时任务：到点后唤醒模型执行。

## 它解决什么

DSH 的定时能力（`schedule`）是"到点给会话发一条用户消息"，适合日历式提醒。
但有些场景需要的是"**隔一段时间，给这个会话一次机会**"，比如：

- 过一阵看看有没有需要跟进的事
- 每隔一两小时给自己一个主动开口的机会
- 到某个时间点提醒自己继续某项工作

tick 就是把这个"机会"做成任务：每种节奏都能配，到点往会话里投一段
**scratch**（留给未来自己的说明），模型据此决定这轮做什么。

## 三种节奏

| 类型 | 参数 | 说明 |
|---|---|---|
| 一次性 | 相对分钟数 或 绝对时刻（带时区偏移） | 到点触发一次 |
| 固定间隔 | `everyMinutes` | 每隔 N 分钟 |
| 随机间隔 | `minMinutes` / `maxMinutes` | 每次在区间内重抽，避免固定节拍 |

## 关键约束

- **一个 job = 一次机会 + 一个意图**：不要把多种目的塞进同一个 job，
  否则频率、预算、补偿策略都无法分别设定
- **静默合法**：任务触发后模型可以什么都不说
- **只做触发路径**：本插件不认识消息、频道、群聊；消息怎么进来由别的角色负责
- **闸与预算**：每 job 每日次数、全局次数、每会话 token 预算都可配
