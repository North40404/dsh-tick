# dsh-tick

给 DSH 会话安排定时任务：到点后唤醒该会话，并带上你留给未来的说明。

## 现在能做什么

**6 个工具**（模型可调）

| 工具 | 用途 |
|---|---|
| `tick_once` | 一次性：`inMinutes`（相对）或 `at`（ISO 8601 带偏移） |
| `tick_repeat` | 周期：`fixed`（固定间隔）或 `random`（随机区间） |
| `tick_list` | 列出本会话的任务（默认精简） |
| `tick_cancel` | 取消一个任务 |
| `tick_update` | 改说明 / 重要性 / 启用状态 / 触发方式 |
| `tick_run` | 立即执行一次（计入日上限） |

**设置页**（设置 → DSH-Tick）

- **总开关**：关闭后所有任务暂停触发（任务保留），重新开启继续；关闭期间仍维持扫描心跳
- 运行参数 9 项，保存后**立即生效**，不需要重启插件
- **错过的提醒**：重要任务错过会留档（含原定时间与迟到时长），确认后可一键清空
- 任务列表：`+` 新建、`编辑`、`×` 删除
- 目标会话下拉框：显示 DSH 会话标题，**已排除归档会话**
  （归档集合取自 `workspaceController.follow()` 的 `archivedSessionIds`；
  `sessionController.list` 本身**不过滤**归档，不能直接用它）

**运行时保障**

- 硬门：活跃窗口 / 单任务次数 / 全局次数 / **当日 token 预算** / 等空闲
- 一次性任务**豁免窗口**（闹钟是指定时刻，不该被免打扰挡掉）
- 迟到：普通任务静默丢弃；**重要任务错过会补一次「告知」**（不执行原任务）
- 自检环：识别睡眠/挂起造成的扫描间断与时钟倒退
- **会话不可达**：目标会话被删时任务被标记并挂起（不无限重试），可在设置页「改绑到所选会话」救回
- 计数与预算**落盘**，重启不会被重置

## 数据

```
~/.dsh/dsh-tick-data/
├── jobs.json     任务定义
├── meta.json     运行状态（lastScanAt / gateState / lastSessionId / missed）
├── settings.json 插件配置
├── runs.jsonl    执行历史
└── tick.log      插件日志（每轮扫描、每次唤醒、错误都在这）
```

## 测试

```powershell
node --test --test-isolation=none test/
```

> 必须带 `--test-isolation=none`：默认模式为每个测试文件开子进程，本机沙箱禁止
> 子进程通过管道捕获输出（`spawn EPIPE/EPERM`），单进程模式可正常跑。

## 已知限制

- **只服务单一会话**：任务绑定创建时的会话；切换目标会话不会迁移旧任务。
- **token 预算是单会话口径**：统计该会话当日 `assistant/message` 的 usage 之和，
  包含你自己聊天用掉的量；**拿不到 API 账户级总花费**（那是服务商后台）。
  **填 0 表示不限制**（不是"全部拦下"）。
- **子代理不能创建任务**：工具全局注册，但创建类工具在非根会话上返回 `subagent_denied`。
  原因：子代理任务会绑到无人查看的会话、抢占全局名额，并覆盖 token 统计口径。

  > 这是设计选择，不是缺陷。如果以后想让"子代理排的提醒"也能用，**正确做法不是放开创建**，
  > 而是让子代理通过主会话转达——它本来就是被主代理派出去干活的，
  > 不该拥有一个人类看不见、也无法取消的定时器。

- **僵尸任务自动清理**：目标会话不可达的任务保留 24 小时供改绑，过期自动移除，
  并在设置页「错过的提醒」里留一条记录。
- **必须先在聊天里建过一个任务**，设置页才有 `lastSessionId` 可选（之后可用下拉框改）。
- **日历型（每天 9 点）不支持**：请用官方 `schedule_create`。
- **没有实时推送**：设置页打开时拉取，任务列表需手动刷新（重新打开页面）。

## 改动须知

1. **改 `index.js`/`client.js` 后要重载插件**：`plugin_manager` 关→开一次；
   linked 目录的源码变更不会自动生效，连续快速重载会撞上
   `HMR transactions cannot be nested`，遇到就等几秒或重启 DSH。
2. **配置不走宿主 Config**：本地 link 安装解析不到 `@deepseek-ai/schemastery`，
   所以配置存在 `settings.json`，校验在 `validatePatch` 里做。
3. **别用 PowerShell 字符串字面量 POST 中文**：会被编码成 `?`；要么用 UTF-8 字节，
   要么走工具调用。
4. **看到乱码先验字节**：`tick.log` 与 `jobs.json` 都是 UTF-8，用显式编码读。
